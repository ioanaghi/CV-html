# HTML CV

Static HTML résumé created as a web-development course project.

## View locally

Clone this repository and open `index.html` in a browser. No package installation or build step is required.

## Structure

`index.html` contains the document and `Assets/images/` contains its image assets. This is an introductory HTML project rather than an application backend.

## Learning focus

Semantic content structure, links, images, and clear presentation. Professional details in an older CV may become outdated; the [GitHub profile](https://github.com/ioanaghi) is the current portfolio entry point.
